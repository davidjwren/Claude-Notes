# claude-notes plugin

Two skills for Claude Notes, a private notes page inside Claude:

- **notes-setup**: publishes the notes page as a private artifact with its database and adds the starter notes. Say "Set up Claude Notes".
- **notes** (`/notes`): saves, finds and edits notes, keeps to-do lists, changes the capture setting, syncs GitHub repositories into notes and edits the page, from any chat.

See the repository README for the full description, the trade-off (notes are shared with Anthropic) and the optional scheduled tasks.
