Claude Notes is one page of HTML that Claude published for you. Claude can change it: colours, layout, buttons, new features. Your notes are kept in the page's database, so changing the page does not touch them.

## How to ask
1. Open a chat with Claude where the artifact tools are available (the Claude app or claude.ai).
2. Say what you want and where, with the page's link: "In Claude Notes, make the sidebar narrower on desktop" or "add a button to the note bar that copies the note as plain text".
3. Claude reads the page, makes the change, tests it where it can, and publishes it to the same link. Reload the page to see it.
4. Check it on the devices you use; ask for adjustments in the same chat.

## Tips
- **One thing at a time** works best, and say which screen it is for (phone, tablet, desktop) if it matters.
- **Describe what you see**, not the code: "the button next to the text is hard to see" is enough.
- **Keep to one chat at a time** for page changes. Two chats editing the page at once can overwrite each other.
- **Ask for the Help notes to be updated** with the change, so the help keeps matching the page.
- **Undo**: earlier versions stay in the artifact's history; ask Claude to go back to the previous version if a change doesn't suit you.
- **Don't delete the artifact**: deleting it erases every note. Download a copy first (Settings → Download all) if you ever need to start again.

## Ideas
- Your own colour scheme, or the accent colour on more buttons.
- Different sections in the sidebar, or a different order.
- New Claude buttons, such as "translate this note" or "turn this into a checklist".
- Templates for new notes, such as meeting notes with set headings.
